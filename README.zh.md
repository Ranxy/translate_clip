# TranslateClip (剪译)

[English](README.md) · **中文**

在任意应用里复制文本，译文就会出现在一个始终置顶的小窗口里。不用切换标签页，不用粘贴到聊天窗口，也不用重新输入。

```
你在某个应用里按 Ctrl+C        →   ┌───────────────────────────┐
                                   │ 剪译             ⏸ 监听中│
                                   │ 原文           EN → 中文  │
                                   │ The quick brown fox …     │
                                   │ 译文                      │
                                   │ 敏捷的棕色狐狸…           │
                                   │ [立即翻译][复制译文] [🗑] │
                                   └───────────────────────────┘
```

## 它能做什么

- **在哪儿复制都行，它会自己翻译。** 监听器轮询剪贴板，你的文本会被翻译并显示在浮层里，通常不到一秒。
- **方向由它替你判断。** 语言检测会决定是把它译成你的目标语言，还是反过来译成回落语言——默认中文 → 英文、其它语言 → 中文——浮层会显示它最终确定的方向。
- **同一段文本再复制一次不消耗额度。** 已完成的译文会在 24 小时内被复用，不再请求模型；浮层会标上*缓存*。
- **它能把译文交还给你。** 开启*自动替换剪贴板*后，每段完成的译文都会直接写回剪贴板，随时可以粘贴到原文本本来要去的地方。默认关闭。
- **用你自己的翻译服务。** OpenAI、DeepSeek、OpenRouter、跑在你本机的 Ollama，或者任何兼容 OpenAI 的接口。
- **历史、术语表和提示词都由你塑造**——可搜索的历史、强制指定的术语、可编辑并带实时预览的提示词模板。
- **不需要快捷键。** 除非你自己录制，否则不会绑定任何全局按键；每个操作都能从浮层和托盘菜单触发。

## 安装

只构建 Windows 10/11 (x64) 安装包。Linux 的情况见*已知限制*。

1. **下载安装包**：在仓库的 *Releases* 页面下载 `TranslateClip-<版本>-x64.exe`，然后运行它。
2. **或者自己构建**——参见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

安装程序可以自选目录，也不需要管理员权限。新版本会覆盖安装旧版本，你的设置和历史都会保留。

> Release 由本仓库的 CI 从对应 tag 构建。安装包**没有代码签名**，所以首次运行会出现 SmartScreen 的「Windows 已保护你的电脑」——点*更多信息* → *仍要运行* 即可。要去掉这个提示需要付费的代码签名证书。

## 首次运行

首次启动会打开一个四步向导：

1. **界面语言与翻译方向**——向导默认跟随系统语言，顶部的下拉框可以立即切换。下面选择翻译成哪种语言，以及文本已经是该语言时该怎么办。翻译方向是必填的，其它步骤都有合理的默认值。
2. **接入翻译服务**——选择服务、粘贴 API Key、拉取模型列表，然后点*测试连接*。这一步可以跳过，之后再配置。
3. **剪贴板与隐私**——什么内容会被发到哪里，以及长度限制、忽略规则和跳过单个词或数字的选项。
4. **系统集成**——开机自动启动、关闭浮层后应用是否留在托盘，以及可选的键盘快捷键。

提前关闭向导也没关系：浮层会显示一张*尚未配置翻译服务*的卡片，点*去配置*就能进入翻译服务页面。

## 使用

### 浮层

| 位置 | 作用 |
| --- | --- |
| 标题栏里的 `⏸ 监听中` | 剪贴板监听的状态，同时也是它的开关：点一下暂停，再点一下恢复。暂停期间复制的内容会被忽略，之后也不会补翻 |
| 标题栏按钮 | `─` 把浮层折叠成一条栏 · `⚙` 设置 · `✕` 隐藏浮层（应用会继续在托盘里运行） |
| `立即翻译` | 立刻翻译剪贴板上的当前内容，不必等它变化；对同一段文本再问一次会直接命中缓存 |
| `复制译文` | 把译文放回剪贴板 |
| `🗑` / `清空` | 清空当前视图——原文、译文，以及正在进行的请求 |
| `当前` / `历史` | 在正在查看的译文和可搜索的历史之间切换 |
| 状态栏 | 阶段、服务与模型、上一次复制**没有**被翻译的原因、自动替换开关，以及 `暂停` / `恢复` |
| 折叠后的条（点 `─` 之后） | 一行译文预览，译文较长时会变高（最多六行，其余悬停查看）。暂停、清空和展开就在旁边，文本换行后它们会竖排成一列，让预览保持宽度 |

### 托盘菜单

*显示浮层 / 隐藏浮层*——这一项会跟随浮层的状态——*立即翻译剪贴板*、*监听剪贴板*、*折叠*、*鼠标穿透*、*设置*、*开机自动启动*（仅安装版）、*打开日志目录*、*退出*。左键单击托盘图标切换浮层显隐，双击打开设置。

### 自动替换剪贴板

在浮层状态栏里打开自动替换开关，或者进入 **设置 → 剪贴板 → 自动替换剪贴板**。此后剪贴板里放的就是你复制内容的译文，而不是原文。它默认关闭，因为它会把剪贴板从你手里拿走；应用能识别自己写入的内容，所以不会把译文翻来翻去。

### 键盘快捷键

默认不注册任何快捷键。在 **设置 → 快捷键** 里点击录制框，按下你想要的组合键（例如 `Ctrl+Alt+T`）。生效后该行会显示*已生效*，组合键属于其它程序时则会给出警告。用 `✕` 清除。

### 历史

浮层里的 `历史` 可以搜索原文和译文，可以复制译文、收藏一条记录、删除单条记录，或者在保留已收藏记录的前提下清空列表。历史最多保存 500 条。

## 配置翻译服务

**设置 → 翻译服务**里列出了 OpenAI、DeepSeek、OpenRouter、Ollama 以及自定义的 OpenAI 兼容接口。选一个，填写模型（或点*拉取模型*从服务端拉取列表），粘贴 API Key，然后点*测试连接*——这个请求只检查地址和密钥，不消耗额度。保存第一个配置后，它就会成为当前使用的配置。

Ollama 不需要密钥：默认地址是 `http://127.0.0.1:11434/v1`。

API Key 用操作系统自带的能力加密（Windows 上是 DPAPI），并且永远不会经过界面进程——只有你显式点开查看时，设置页才会读取它。在没有密钥环的 Linux 系统上，设置页会直接说明这一点，而不是假装密钥是安全的。

## 设置项，一行一个

**通用**——界面语言、主题、浮层透明度（滑块，拖动时浮层实时变化）与字号、开机自动启动、关闭浮层时保留在托盘、历史记录上限，以及打开数据目录和日志目录的按钮。**剪贴板**——监听、检测间隔、长度限制、忽略规则、跳过单个词/数字、复用缓存、自动替换、记录 LLM 请求日志。**翻译服务**——同上。**提示词**——系统提示词模板、可用变量和实时预览。**术语表**——强制译法，支持 JSON 导入导出。**快捷键**——录制框。**关于**——版本、平台诊断，以及*重新运行初始向导*。

## 隐私

- **你复制的内容会发送到你配置的服务。** 这正是这个应用存在的意义，设置页也写明了这一点。除此之外没有任何东西会外发：没有遥测、没有账号、没有云同步。
- 控制权始终在你手里：暂停监听、添加忽略规则（URL 和纯数字是现成的建议规则）、设置最短和最长长度、跳过单个词或数字。
- 其余一切都留在你自己的机器上——历史、术语表、窗口位置。

## 数据存放位置

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\translate-clip\config.json` | 所有设置和术语表 |
| `…\data.sqlite` | 翻译服务配置和翻译历史 |
| `…\window-state.json` | 窗口位置和大小 |
| `…\logs\main.log` | 应用日志，超过 2 MB 时轮转 |

*设置 → 关于*会显示确切路径，并可以打开该目录。删除整个目录会把应用重置回首次运行的状态，向导也会重新出现。

## 已知限制

- **独占全屏运行的游戏会遮住浮层。** 这是 Windows/DWM 的规则，而不是应用能绕开的问题；请把游戏改成无边框窗口模式。
- **透明是有代价的。** 透明的置顶窗口没有投影，而且在某些显卡驱动上毛玻璃效果会很慢——**设置 → 通用 → 使用不透明背景**可以用纯色换掉模糊。
- **鼠标穿透会让浮层点不动。** 这本来就是它的用途；从托盘菜单关掉即可，你开启的那一刻浮层也会提示这一点。
- **没有 Linux 构建。** 源码里保留了 Linux 分支——托盘降级、X11 快捷键、密钥环探测、窗口透明度能力上报——但不出包，这些分支也没有被测过，不提供支持。
