# Windows 验证清单

这份清单是自动化测试覆盖不到的部分。Linux/WSL 侧已经验证过:构建、类型、128 个单元测试、
以及 `--self-check`(资源、asar 布局、sql.js wasm、剪贴板管线、真实翻译、全部设置页、向导)。
**而"真实 Windows 桌面环境"里的行为只能在 Windows 上验。**

每一条都给了**预期结果** —— 不一致就是 bug,请按最后一节提供信息。

---

## 0. 准备

| 方式 | 命令 / 操作 | 用途 |
| --- | --- | --- |
| 开发运行 | `npm install` → `npm run dev` | 快速迭代;此时**开机自启不可用**(UI 会置灰说明) |
| 安装包 | `npm run dist:win` 或 Actions 页下载 | 验证真实安装体验、自启、托盘图标 |

自动化自检(两条都要跑一次):

```
npm run self-check
```

预期:末行 `[self-check] PASSED`(`"ok": true` 共 20 条)。安装版也可以跑:
`"<安装目录>\TranslateClip.exe" --self-check`(会临时建一个指向本机回环 stub 的
provider 并自动删除,不使用你的真实配置,也不会启动剪贴板监听)。

注意:**应用正在运行时跑 `--self-check` 会直接报错退出**(退出码 2,提示先退出应用),
而不是静默什么都不做 —— 两个进程同时写同一个 `data.sqlite` 会互相覆盖。

## 1. 首启向导

1. 清空配置目录(`%APPDATA%\translate-clip`)后启动。
2. 观察:浮层出现 + 向导窗口自动弹出。
3. 第 1 步把目标语言与回落语言设成**相同**。
4. 第 2 步不填任何东西,点「下一步」。
5. 第 3、4 步直接「完成」。

| # | 预期 |
| --- | --- |
| 2 | 向导 4 步;顶部步骤条可点回已完成的步骤 |
| 3 | 「下一步」**置灰**,并显示"目标语言与回落语言不能相同" |
| 4 | 允许跳过(这是设计),不报错 |
| 5 | 向导关闭;浮层显示"尚未配置翻译服务 / 去配置" |

再启动一次 → **不再弹向导**。设置 → 通用 → 「重新运行初始向导」→ 向导重新弹出。

## 2. 剪贴板链路

先配置一个 provider(见 §5),然后依次复制下列内容:

| 复制内容 | 预期 |
| --- | --- |
| 一段英文段落 | ~0.4s 内浮层显示原文 + `AUTO → ZH-CN`,随后出现译文 |
| 一段中文 | 方向变成 `ZH-CN → EN-US`(智能互译) |
| 同一段英文(再复制一次) | 立即出结果并带"缓存"标记,**不产生新请求**(开 `llmDebugEnabled` 可在日志看到只有 1 次请求) |
| 只有 1 个字符 | 状态条显示"已跳过:内容过短" |
| 一个纯数字如 `1234567` | 默认**会翻译**(`skipSingleToken` 默认关);在设置里打开后变成"已跳过:单个词或数字" |
| 超过 5000 字符的长文 | 状态条"已跳过:内容过长"(不截断,避免错译) |
| 一张图片 | 无任何反应(只处理文本) |
| **在资源管理器里复制一个文件** | 状态条显示"已跳过:复制的是文件而非文本",**不翻译**(Windows 复制文件时也会把路径放进文本剪贴板) |
| 上一条之后点「立即翻译剪贴板」 | **会翻译** —— 显式请求不被该规则拦截 |
| 快速连续复制 3 段不同文本 | 只翻译最后一段;前两次请求被中断,**不会**出现过期译文覆盖新译文 |

暂停监听(托盘或状态条上的"监听中")后复制 → 无反应;恢复监听后**不会**追翻暂停期间的内容。
用浮层空态的「立即翻译剪贴板」→ 即使内容与上次相同也会翻译。

## 3. 浮层

| 操作 | 预期 |
| --- | --- |
| 让它与浏览器/记事本/终端重叠 | 浮层始终在最上层 |
| 拖动标题栏 | 可移动;重启应用后位置保持 |
| 「─」折叠 | 收成一行(标题 + 译文首行);再点展开回原高度 |
| 「✕」关闭 | 浮层隐藏;应用仍在托盘运行,剪贴板监听继续 |
| 设置里调透明度 | 立即生效 |
| 开启鼠标穿透 | 浮层不再响应点击;出现"请从托盘关闭"提示 |
| 在穿透状态下复制新文本 | **仍然会翻译**,浮层照常更新(只是不能点) |
| 从托盘关掉穿透 | 恢复可点击 |
| 分辨率缩放改成 150%,重启应用 | 文字不模糊、位置仍在屏幕内 |
| 折叠状态下退出应用并重启 | 仍是那条短条(不会变成一条很高的空条);展开后恢复 520 高度 |
| 双显示器:把浮层拖到副屏,拔掉副屏后重启 | 浮层回到主屏可见区域内(不会跑到屏幕外) |
| 独占全屏的游戏 | **盖不住** —— 这是 Windows/DWM 的限制,把游戏设为"无边框窗口"即可 |

## 5. 提供商与密钥

| 操作 | 预期 |
| --- | --- |
| 选 DeepSeek,粘贴 API Key,点「拉取模型」 | 出现可筛选的模型列表 |
| 点「测试连接」 | 绿色"连接正常(xxx ms)" |
| 故意填错 API Key 再测试 | 红色"连接失败:API Key 被拒绝…" |
| 保存后复制文本 | 正常翻译 |
| Ollama(本机已跑 `ollama serve`) | 不需要填 Key;地址默认 `http://127.0.0.1:11434/v1`;能拉到本地模型 |
| 把 `%APPDATA%\translate-clip\data.sqlite` 用任意文本编辑器打开 | **看不到明文 API Key**(Windows 走 DPAPI 加密;设置页不应出现"无密钥环"警告) |
| 添加第二个 provider 配置并「设为当前」 | 状态条与后续翻译切到新配置;旧配置保留 |
| 删除当前生效的配置 | 自动改用剩下的最近一个;没有配置时回到"尚未配置" |

## 7. 开机自启(需要安装版)

1. 设置 → 通用 → 打开「开机自动启动」。
2. 任务管理器 → 启动 标签:应出现 TranslateClip。
3. 注销并重新登录。

| # | 预期 |
| --- | --- |
| 2 | 出现该条目 |
| 3 | 应用自动启动,**不弹向导、不弹设置窗口**,只出现浮层并开始监听 |
| 再次打开设置 | 开关仍是"开"(不会读回关闭状态) |
| 关闭开关 | 启动项被移除(任务管理器里消失) |

开发运行(`npm run dev`)下该开关**置灰**,并提示"开发模式下不会写入系统启动项"。

## 9. 如果某一条不符

请提供三样东西,基本就能定位:

1. 出问题的那一条编号 + 你看到的现象(截图最好)。
2. `npm run self-check` 的完整输出(或安装版 `TranslateClip.exe --self-check`)。
3. 日志:`%APPDATA%\translate-clip\logs\main.log`(设置 → 关于 → 打开日志目录)。

日志里已经包含:平台能力探测、剪贴板每次接受/跳过的原因与字符数、每次翻译的耗时与
provider/model、以及所有错误分类。开 `llmDebugEnabled` 还会记录发给模型的完整提示词。
